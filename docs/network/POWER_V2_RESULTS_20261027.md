## 改动与边界

- V1 已处理有可靠吸附证据、但没有可见物理脚号的单端子符号导出。两份材料中的“37/6/1”不能用统一设置 exportable=True 解决。
- V2 只补 V1 中没有端点证据的对象。原图局部走廊必须至少 90% 有线迹，最长空白不超过一个线宽，方向一致，不穿过其他元件；多个网络相近则拒绝。未知供电 value 仍拒绝新增公共轨。
- 新增 Wire 输出适配器只携带电源符号局部原图裁剪；原 mask、suppression、corridor 不变。没有修改 Pin 链、Component、legacy_v2 或模型。
- 所有原有物理分组、路径 ID、接触点和组内线段几何均保持一致。第四项变化来自原有分支被导出及逻辑网络匹配变化，不能写成线段提取算法改善。
- 标准入口 0040 的 V2 输出与冻结输入重放逐字段一致。完整回归 400 项通过，集成范围检查通过。

# 第三项逐阶段错漏诊断：当前 N1/N2＋L39＋供电 V2

结论：主要瓶颈是**进入分网前的成员身份缺失**，其次是**已有身份之间的分组连通失败**。GT 网络成员身份漏了 70.04%；仅凭当前已入网身份，即使允许理想分组、删除多余身份和自由选择网络数量，第三项宏平均 F1 的乐观上限仍只有 42.07%。当前为 24.102%。

本报告只分析封存的 0001—0150，使用同一 `pin_protocol2055` 本地语义，不是官网评测。没有改模型、阈值、默认配置或推理规则，也没有重新运行上游识别。之前的 635 个错对、6692 个漏对是**共同正确身份上的条件统计**，不能代表端到端全部错误；本次补齐了全身份统计。

|---|---:|
| GT 逻辑网络 | 5392 |
| 预测逻辑网络 | 4798 |

“完全相同”只针对第三项成员集合，不代表线段或其他三项也正确。530＋1530＝2060 个网络对有正重叠，但大量网络只对了一小部分成员。

评分器把每个匹配网络的成员 F1 累加作为软 TP：合计 TP＝1362.406、FP＝3435.594、FN＝4029.594。它们是软计数，不能说成“错了 3436 个完整网络”。合并所有计数的微平均 F1 为 26.740%，主报告使用逐图宏平均 24.102%，两者口径不同。

## 2. 首要瓶颈：网络成员身份

以下按每图去重后求和：IC 按“位号＋脚号”，普通元件按位号，电源按轨。不是元件实例数、端子总数或网络数。

| 身份类别 | GT 身份 | 正确保留并入网 | 漏身份 FN | 多出的预测身份 FP |
|---|---:|---:|---:|---:|
| IC 引脚身份 | 6133 | 1041 | **5092** | **1265** |
| 普通元件身份 | 3213 | 1605 | 1608 | 202 |
| 电源轨身份 | 383 | 269 | 114 | 32 |
| 总计 | **9729** | **2915** | **6814** | **1499** |

6814 个漏身份中，5092 个是 IC 引脚，占 74.73%。这是第三项目前最大的输入缺口。错身份不是“吸附距离稍微偏一点”，而是最终引用根本不是 GT 要的那个成员，后续并查集合并无法补回正确位号或脚号。

### 漏身份首次发生在哪一步

按真实依赖顺序分配，每个缺失 GT 身份只记一次：

| 首次失败环节 | 新增漏身份 | 细分 |
|---|---:|---|
| 可用元件位号或电源轨身份未对上 | **5247** | IC 引脚身份 3654、普通元件 1525、电源轨 68 |
| 元件身份存在，但原始端子没有正确 IC 脚号 | **1438** | IC 引脚 1438 |
| 仍无合法可导出端子 | **129** | 普通元件 83、电源轨 46 |
| 合法身份导出后未进入任何网络 | **0** | 全部合法身份都出现在某个输出网中 |
| 总计 | **6814** | 与上表完全对齐 |

5247 的单位是“折算后的网络成员身份”，不是 5247 个元件；一个芯片位号不对会同时丢失多个引脚身份。第一行无法仅凭名字区分漏检与错位号；第二行无法仅凭原始输出区分漏定位与编号识别错误，本报告不强行细分。

最后一行的 0 不代表全部连接正确：未吸附的引脚也可能被输出成孤立单点网。

### 当前身份能够达到的乐观 F1 上限

| 可用身份停在哪一步 | 乐观上限 |
|---|---:|
| 元件位号、供电 value 等身份固定，假设后续端子完美 | 53.3667% |
| 再固定现有原始 IC 脚号 | 44.1817% |
| 再固定合法可导出身份 | **42.0688%** |
| 再固定实际已入网身份 | **42.0688%** |
| 当前真实第三项 | **24.1025%** |

上限的计算：GT 网 (S_j) 中可用身份为 (A_j)，其成员重叠权重至多为 `w_j=2|A_j|/(|A_j|+|S_j|)`。将 w 降序排列，对所有 `k=1..GT网数` 取 `2*sum(top_k(w))/(k+GT网数)` 的最大值，再逐图宏平均。它允许删掉错身份、忽略实际几何和端子唯一性约束，是严格偏乐观的松弛界。当前与该界还差 17.9663 个百分点，但这不是可承诺的实际提分空间。

## 3. 把端到端漏连接分配到各阶段

这里统计 GT 同网的无序成员对，包含全部身份；与第三项网络 F1 互为补充，不能直接换算成官网分数。

GT 共有 **40725 对**应连接关系；预测得到正确连接对 **2583**，错连接对 **1706**，漏连接对 **38142**。

| 首次造成漏连接的环节 | 漏连接对 |
|---|---:|
| 元件位号或电源轨身份不可用 | **26132** |
| 正确元件下，正确 IC 脚号未产生 | **3895** |
| 缺少合法端子 | **699** |
| 合法身份被漏出网络 | **0** |
| 两端身份均已入网，但分组仍不连通 | **7416** |
| 总计 | **38142** |

前四行是依赖顺序下的互斥分配：一个 GT 对只有在之前还具备两端身份、此阶段才失去某端时才记入。身份缺失共造成 **30726 对，占全部漏对 80.56%**；分组不通为 7416 对，占 19.44%。

1706 个错对中，**936 对至少有一个身份在 GT 网中不存在**，另有 **770 对两端身份都存在但被错误并网**。

剩余 7416 对漏连中，只有 **78 对**至少一端完全没有进入任何带导线路径的物理组，另有 **7338 对**两端都已接上某些导线路径，却没有成为同一正确逻辑网。这说明“有线可吸附”和“接到正确网络”差别很大；后者仍可能受错吸附、导线断裂/切分、交点判断以及未合并标签影响，现有证据不能把这 7338 对进一步唯一归因。

## 4. 第三项内部各次合并分别增加多少错对、修复多少漏对

为了与上次 635/6692 的统计严格对齐，本节固定原版、V1、V2 与 GT 都具备的共同身份；GT 对数为 **8757**。它排除了缺失或错误身份，只看这部分成员如何分组。

吸附选择先固定，再把同一批引脚投到独立路径上，按原算法顺序回放后续合并。故首行已经包含吸附的好坏，不能把中间“吸附建节点后计数不变”解释成吸附零错误。最后才按所有电源轨归并，避免重复计数。

| 回放阶段 | 正确连接对 TP | 错对 FP | 漏对 FN | 本步新增错对 | 本步修复漏对 |
|---|---:|---:|---:|---:|---:|
| 独立路径，固定原有吸附选择 | 94 | 13 | 8663 | — | — |
| 执行交点连通/分离规则 | 396 | 139 | 8361 | **126** | **302** |
| 执行短断口补连 | 397 | 143 | 8360 | **4** | **1** |
| 执行近距离端子接触合并 | 397 | 143 | 8360 | 0 | 0 |
| 执行重复引用强制并网 | 397 | 143 | 8360 | 0 | 0 |
| 加 V1 合法电源端子，尚不按轨归并 | 427 | 156 | 8330 | **13** | **30** |
| 加 V2 原图墨迹证据，尚不按轨归并 | 429 | 156 | 8328 | 0 | **2** |
| 最后按电源轨归并 | **2065** | **635** | **6692** | **479** | **1636** |

最终 635 个错对可精确分解为：`13 + 126 + 4 + 0 + 0 + 13 + 0 + 479`。

原算法在这批图中记录了 13671 个多臂连接交点、987 个分离交叉点、205 次短断口补连、64 次近距离接触、4 组重复引用。**触发次数不是错误次数**，例如不能把“修复 1 对 / 205 次”当作补连准确率；大量操作没有两侧可核对的共同身份。

按轨归并贡献了最终条件错对的 75.43%，也修复了大量漏对。不能据此直接取消合法电源轨归并：它会把前面错接的物理分支、电源身份或 value 错误放大成跨分支错对。应检查进入轨的分支是否可靠。V2 相对 V1 在最终按轨归并后为正确对 +159、错对 +35；不能只用表中归并前的 +2 对评价 V2。

这张表不能给出“13671 个交点中到底错了几个交点”：GT 没有逐交点真值标签，成员对变化也与前后步骤有关。这里给出的是固定吸附下，每一步实际新增的错连接对和修复的漏对，不冒充独立规则错误率。

## 5. 吸附到底接对多少

几何诊断使用现有 5px 尺度：查看吸附点附近的 GT 线段属于哪个逻辑网。它不是官方吸附标签；处于交叉附近、GT 没画该小段或无附近线段时保留不确定状态。

原始端子实例共 8460 个，其中 8021 个发生了方向吸附、439 个未吸附。拥有可导出引用的实例有 5950 个（不按身份去重，可能包含同引用的重复实例）：

| 状态 | 实例数 |
|---|---:|
| 吸附点附近只出现与身份相容的 GT 网 | **3164** |
| 引用身份不在 GT 网中 | **1641** |
| 身份存在，但吸附点只靠近其他 GT 网 | **405** |
| 附近没有 GT 线段，无法据此判断 | **580** |
| 附近多个 GT 网，几何判断有歧义 | **54** |
| 未吸附 | **106** |
| 总计 | **5950** |

高吸附率不等于高正确率。405 个异网几何案例可能是引脚位置先错，也可能是选线错误，不能全部记给方向吸附规则。580 个无 GT 线段支持的案例也不能直接算成错。

## 8. IC 引脚上游补充对账

第二项口径中的 GT IC 引脚共有 6391 个，预测 2306 个。位号和脚号完全一致的只有 **1071 个**；5320 个 GT 引脚身份未命中，1235 个预测身份不匹配。第二项与“GT 网内成员”口径的分母不同，不能与第 2 节直接相减。

在 1071 个身份已知的引脚中，脚名错 481 个、位置偏差超过 5px 的 337 个，两者重叠 280 个，名字和位置都正确的 533 个。**脚名错本身不直接扣第三项成员身份分**；正确位号、正确脚号和能连接到正确导线的位置更应优先。

## 9. 下一步优先级与证据限制

1. 先修 IC 位号与脚号闭环：当前第三项缺失 5092 个 IC 引脚身份，多出 1265 个 IC 预测身份，是最大的可观测缺口。
2. 再修导线召回与跨物理组的正确连通：7416 个已知身份漏对中 7338 对两端都有线，继续单纯放宽吸附距离并不能保证接对。
3. 第三项内部优先审查进电源轨的分支和 value：按轨归并新增 479 个条件错对；先拦截错误分支，再做全局归并。
4. 交点规则仍有误并，但不是唯一大头；短断口补连在这套共同身份上只修复 1 对、增加 4 对，不应继续靠扩大搜索半径期待主要收益。

KD 树负责找候选，并查集负责执行合并；更换这些数据结构不能补回错误或不存在的成员身份。本报告没有据诊断结果改任何推理参数。

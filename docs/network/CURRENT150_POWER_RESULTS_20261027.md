## 2. 统一的版本和评分口径

| 环节 | 固定版本 |
|---|---|
| Text | recovery_rotation_vertical_v1 |
| Component | rotation_vertical_n1_n2_v1 |
| Pin 定位 / 语义 | l39 / l39 |
| Wire | v3_frame_guard |
| 原版 Topology | v3 |
| NetHypergraph / NetLine | legacy_v2 / legacy_v2 |
| 飞线标签合并 | false |

这里的上游是 N1/N2＋L39；独立提交 ZIP 的 L45＋T 不是同一组合。旧预测中“GND 已经接通”的情况不能套用到本轮版本：当前 L39 原版的 1545 个 GND 符号都没有合法导出端子，因此没有进入最终网络。

评分器来自交接资料，原始源码 SHA-256 为 `66b9ba3172f766e6cecc58164e60cc4d5c8021543da80fa5fc740858aeed4558`。沿用相同函数和匹配依赖，来源校验见 `peer2055_provenance.json`。它不是主办方官方 evaluator，也不与旧 `evaluate_v2` 的分数混比。

该口径按 GND 类型、供电 value 归并电源轨，第三项在逻辑网络匹配后累加网络成员重叠 F1 作为软 TP，再按预测和 GT 网络数归一化。它不是“全部匹配成员数 / 总成员数”。IC 引脚单独计第二项；第四项在已匹配逻辑网络内比较线段。权重为 0.30 / 0.25 / 0.35 / 0.10。

评分器会把旧的空供电 value 当作 VCC；本轮没有修改该定义。接入层拒绝为没有供电 value 的符号新增引用，避免人为创造默认 VCC 轨；原版已有的导出仍保留。

## 3. 电源究竟接通了多少

以下是预测侧符号数量，不是 GT 命中数量。

| 项目 | 原版 | V1 | V2 |
|---|---:|---:|---:|
| GND 符号总数 | 1545 | 1545 | 1545 |
| 有合法端子并进入网络的 GND | 0 | 1309 | **1355** |
| 供电符号总数 | 670 | 670 | 670 |
| 有非空供电 value 的符号 | 561 | 561 | 561 |
| 有合法端子并进入网络的供电符号 | 36 | 328 | **389** |
| 物理导出网络数 | 5165 | 6117 | 6166 |
| 按电源轨归并后的逻辑网络数 | 5156 | 4834 | 4798 |

GT 逻辑网络总数为 5392。网络数下降本身不代表更准确；缺失的身份、漏检和错误连接也会影响数量，采用依据是完整评分与固定身份对照。

V2 新增 1708 个合法电源引用：1355 个 GND、353 个供电。方法分布为原有方向吸附 1416 个、符号边界附近导线端点 185 个、原图连续墨迹补证据 107 个。V2 相比 V1 额外恢复 46 个 GND 和 61 个供电符号。

仍有 363 个符号没有得到支持端点，109 个供电符号缺少供电身份，10 个存在不同导线组歧义；这些情况没有强行接入。25 个已有可导出端子的符号受保护。拒绝原因包含旧版已导出但 value 缺失的情况，不能简单把拒绝总数当作最终未联网符号数。

## 4. 固定共同身份上的拓扑代价

三种预测与 GT 使用同一组共同身份计算连接对，避免把新增身份直接混进不同分母。这些数字是成员对，不是候选边，也不能用来推算候选边精确率。

| 全部 150 例 | 错误连接对 | 漏连接对 |
|---|---:|---:|
| 原版 | 143 | 8358 |
| V1 | 600 | 6851 |
| V2 | **635** | **6692** |

V2 相对原版净修复 1666 个漏连接对，同时净增加 **492 个错误连接对**。误连接确实上升，不能把这轮结果描述为“错误连接也减少”。它通过的是预先约定的预算：新增错误对不超过修复的漏连接对。

## 6. 实现、冻结范围和复现证据

V1 先把已有且能吸附到导线的隐藏电源引脚转换成单端子合法引用，保留其原坐标；不足时仅使用原有距离范围内、靠近符号边界的物理导线端点。拒绝未知供电 value、非法坐标和不同导线组歧义。

V2 只处理 V1 中“没有支持端点”的拒绝，额外读取显式传入的局部原图裁剪。搜索范围不超过 24px；要求墨迹覆盖率至少 90%、最长空缺不超过一个线宽、向外方向一致性至少 0.7，且不能穿过其他器件。它不生成新导线像素、不合并已有物理组、不修改普通引脚。

同一份 Scene 和 WireGraph 生成三组结果。150 例原版重放完全一致，450 份输出均通过严格格式和引用合法性检查；组件导出字段、普通引脚、物理组的路径及接触点归属、组内线段几何全部一致。

第四项的提高来自原先无合法成员的组开始导出现有线段，以及电源轨归并后的网络匹配变化；不是新的线段提取或切分算法收益。

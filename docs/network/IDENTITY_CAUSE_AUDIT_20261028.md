# 位号与电源轨身份缺失：第一步原因分解

结论：这次追踪的 5247 个缺失网络成员身份中，最大的可见障碍是**已有元件框，但存档 OCR 候选没有完整正确位号：3758 个，占 71.62%**。其中 2791 个是 IC 引脚身份。位号缺失随后又导致大量真实候选框未保留；单独恢复框，并不能自动获得正确身份。

本轮只诊断，不改变模型、配置、位号、value、引脚、导线或分网规则，也不生成修正预测。只使用冻结的 0001—0150；未读取保留验证集。第三项仍沿用上次本地宏平均 F1 24.1025%，这不是本轮提分结果或官网分数。

## 1. 分母与分类方法

- 与上一轮逐例对齐：缺失身份 5247＝IC 引脚身份 3654＋普通元件身份 1525＋电源轨身份 68。
- 非电源部分对应 1943 个真实元件位号，折算为 5179 个网络成员身份。一个芯片位号缺失可同时损失多个引脚身份。
- 用元件框做一对一几何匹配，**不使用位号或类型决定匹配**。固定诊断门槛 IoU≥0.5，先最大化匹配数量、再最大化 IoU。
- 一个框可能匹配多个 GT，或一个 GT 可能匹配多个框，均保留为歧义，不强行归因。
- 同时检查最终元件、P01 过滤前候选、融合丢弃记录、共享 OCR、已存档的局部 PARSeq 接受结果和位号角色记录。
- 分类先隔离几何不确定、缺框、类型和大小写等情况，再检查文字、角色与关联评分。多种问题可能共存，互斥表只分配一次，不代表各项独立的因果贡献。
- “存档候选没有完整正确位号”包含漏读、错读、粘连/切分失败以及未保存的候选等可能性，**不能细分为文字检测错误或识别模型错误**。没有重新识图或调参。

## 2. 非电源缺失身份的互斥分解

若框被过滤，则继续检查过滤前的身份与文字证据，避免把已经缺失位号的框都归咎于过滤。每个缺失身份在本表只出现一次。

| 最早可见的身份障碍 | 真实元件数 | IC 引脚身份 | 普通元件身份 | 合计身份 |
|---|---:|---:|---:|---:|
| 有框，但存档候选无完整正确位号 | 1303 | 2791 | 967 | **3758** |
| 有完整文字，但未进入正确的位号角色候选 | 66 | 327 | 34 | **361** |
| 有正确候选，但现有关联评分/门槛不通过 | 31 | 112 | 21 | **133** |
| 有达标候选，仍未形成正确身份：关联或键冲突待查 | 55 | 110 | 46 | **156** |
| 对应框的位号仅大小写不同 | 11 | 123 | 6 | **129** |
| 对应框的类型不相容 | 45 | 5 | 43 | **48** |
| 融合丢弃记录中有可匹配框，最终未恢复 | 10 | 0 | 10 | **10** |
| 过滤前没有达到诊断 IoU 的框 | 405 | 87 | 386 | **473** |
| 几何匹配有竞争或歧义，暂不归因 | 17 | 99 | 12 | **111** |
| 合计 | **1943** | **3654** | **1525** | **5179** |

“过滤前无匹配框”不等于已经证明原始 YOLO 完全没有检测：存档不能追到每个原始、阈值前的检测框，且 GT/预测框大小差异也可能导致 IoU 不足。此处保留较弱的证据表述。

## 3. 过滤如何放大身份缺失

最终没有保留、但过滤前存在明确对应框的部分，共 **1242 个元件、3789 个成员身份**，占全部 5247 个缺失身份的 72.21%。过滤前这 1242 个框的键**全部为 `UNRESOLVED_*`**，并非已经拥有正确位号却被统一删掉。

| 这 1242 个未保留框的更早问题 | 元件数 | 身份数 |
|---|---:|---:|
| 存档候选无完整正确位号 | 1143 | **3379** |
| 有完整文字，但未进入正确位号角色候选 | 42 | **251** |
| 有候选，但现有关联评分/门槛不通过 | 19 | **118** |
| 候选框类型不相容 | 32 | **35** |
| 有达标候选但身份仍未确定 | 6 | **6** |
| 合计 | **1242** | **3789** |

这些已与 GT 几何对应的候选，检测置信度中位数为 0.7023，范围 0.1005—0.9853。不能只凭“被过滤”就说检测器没看到，也不能把它们全恢复后算成身份修复。

当前 N1 恢复逻辑已经尝试补回“有观察到的位号且未占用”的过滤候选；在本轮可明确几何匹配的缺失记录中，**过滤前已有完全正确身份、但最终身份消失的记录为 0**。主要链路是：没有形成正确位号 → `UNRESOLVED_*` → 未被保留 → 无法进入正确身份网络。

## 4. 两个可直接核对的例子

### 0001：U1，涉及 72 个 GT 网络引脚身份

- 过滤前存在 IC 框：`UNRESOLVED_0026`，检测置信度 0.2927。
- 原始 OCR 已读出 `U1`，置信度 0.98982，也已被分类成位号。
- 现有关联权重只有 **0.0180466**，低于原有 **0.055** 接受门槛。
- 该框随后未保留。因此这个例子优先检查关联评分与布局，换 OCR 不是解决本例的必要条件。

这里的阈值是当前实现已有值，本轮没有据 GT 调整它。

### 0102：XOU21，涉及 45 个 GT 网络引脚身份

- 过滤前存在 IC 框：`UNRESOLVED_0002`，检测置信度 0.8079。
- 原始 OCR 已完整读出 `XOU21`。
- 该字符串被归类为 `MODEL_TEXT`，没有进入正确位号候选，最终框未保留。
- 这个例子优先检查位号语法/角色判断，不应归类为“识别模型没读到”。

全体缺失非电源身份中，666 个的完整 GT 位号不能被当前位号语法完整接受，其中 163 个已有相同完整文字观测。这是交叉证据，**不能再加到第 2 节总数中**。

## 5. 大小写与“同名绑错框”

- 全图存在大小写等价别名的缺失身份共 132 个；其中 129 个获得明确的同一元件框证据，另外 3 个几何未确认。
- 129 个只涉及 11 个元件，其中 128 个对应的存档 OCR 也没有 GT 要求的精确大小写，仅 1 个已有精确写法。
- 例如 0001 的 GT 为 `u2`，对应预测和原始 OCR 都为 `U2`。这是评分身份不一致，不能仅凭这次统计断言画面中的正确字形应该小写，也不能直接把全部输出统一改小写。
- 另发现 **102 个元件、187 个成员身份**：其位号在全图存在，但对应名称所在框与 GT 的 IoU<0.5，而 GT 框明确匹配了另一个名称的预测框。这是错绑的额外几何证据，不在原 5247 个“名称或轨全局不存在”的桶中，不能重复相加。

## 6. 68 个缺失电源轨身份

一条轨可由多个 GT 电源符号表示。本节先逐符号诊断，再按轨汇总；若同一轨的多个符号失败原因不同，则归入混合项。

| 轨级情况，互斥 | 轨数 |
|---|---:|
| 所有对应符号均无过滤前严格几何匹配 | **31** |
| 对应供电符号存在，但非空 value 与 GT 不同 | **14** |
| 对应供电符号存在，但 value 为空 | **14** |
| 对应 value 仅大小写或空白不同 | **2** |
| 同轨多个符号有不同失败原因 | **6** |
| 可匹配符号仅见于融合丢弃记录 | **1** |
| 合计 | **68** |

这些轨共对应 98 个 GT 符号实例：非空 value 不同 27、空 value 24、大小写/空白差异 2、无过滤前严格匹配 44、仅融合记录 1。不能把实例数当作轨数。

另有以下非互斥证据：21 条轨至少有一个非空 value 不一致的对应符号；18 条至少有一个空 value 符号；49 条在全图存档中能找到与 GT value 对应的完整文字。最后一项不证明文字位于符号附近或能合法关联。

其中 **9 条轨的所有 GT 符号 value 都为空**，按现有本地评分器回退为 `VCC`。这类差异需区分评分器回退、GT 记法与图上文字，不能全部解释成 OCR 把字符读错。例如 0003 的 GT 默认轨为 `VCC`，对应预测为 `VCC_RF`；本轮只记录差异，不利用 GT 覆盖预测。

当前 `recover_power_values()` 只填空 value，不纠正已有非空 value，确实覆盖不到“已有错误 value”的一部分；需要后续独立实验验证。

## 7. 导出边界与下一步顺序

150 例最终 Scene 与冻结 V2 的元件键集合、类型和 value 全部一致，**没有发现最终导出阶段丢失已有身份，计 0**。未确定身份与过滤问题发生在更早阶段。

下一步建议按以下顺序做独立对照，本轮尚未执行：

1. 先处理已有文字被挡住的链路：位号角色/语法 361、现有关联门槛 133、达标候选仍未成身份 156。先复用已有识别结果，逐项核验收益和错误身份增量。
2. 主量投入已有框的位号局部识别：3758 个身份缺完整文字，其中 2791 个是 IC 引脚身份。保留原候选，专门检查位号邻域裁剪、粘连与竖排/旋转等来源，不能靠给未识别元件顺序编号来补身份。
3. 在完成上述身份恢复后，检查 P01 的保留与恢复策略；单独降低过滤阈值无法补回缺失的正确位号。
4. 电源侧区分缺符号、空 value、非空错误 value；先以独立开关评估非空 value 纠正，保留轨归并的错连接监控。

大小写的确认量仅 129，且多数原始 OCR 也无 GT 精确写法，不作为本轮最大的可预期收益。所有数字是诊断计数，不能直接换算为可保证的第三项提分。

## 为什么需要独立集成

Component 恢复只能增加组件和 value。网络私有视图不能创建引脚，导出器又仅接受可导出的已有引脚引用。因此单改分网模块不能修复电源端子缺失。集成层可以访问完整 Scene 和冻结的 WireGraph，在执行原分网后向既有组增加一个有导线证据的电源端子。全局轨归并属于评分归一化，不生成不存在的跨图几何线段。

预定接口：新增可选择的 `v3_power_terminals_v1` Topology 适配器；保留 v3 原样。新适配器复用原分网计划及原线段后端，只增加/导出 gnd、v 的单端子；已有组之间不执行合并，普通成员、路径归属、原有引脚坐标保持不变。value 不明的供电符号不按空值形成公共轨。

# Open_GT 13 样本 NetLine Wire 几何对比

本报告复用既有 13 样本预测与配对 GT；没有重新运行推理。所有几何指标均为非官方诊断指标，第三方评测器的 Wire F1 规则没有修改。

## 计算方法
- GT 覆盖：以每条 GT 相邻点线段为单位，计算预测线段 5 px 欧氏距离带内的投影区间并集；覆盖率达到 80% 的 GT 线段另计比例。
- 预测几何精度：计算预测线段长度中，距任一 GT 线段不超过 5 px 的长度比例。
- 宏平均：先对每个样本计算比例，再对样本等权平均；长度加权：先累计覆盖长度，再除累计总长度。
- Wire F1 是基线 evaluation.json 中已有暂定评测结果，仅作参照，不代表官方得分。

## 变化归因与结论
- GT 几何覆盖改善样本：1, 8, 10；下降样本：13。
- 预测几何精度下降超过 0.5 个百分点（疑似新增错误几何，仍需人工复核）样本：无。改善样本：11。
- 导出网络成员集合跨版本不一致样本：无。这只能说明导出的网络成员相同，不能证明 group/path provenance 相同。
- 预测线段数减少且覆盖与精度近似不变的样本，更符合几何表示合并/拆分变化；覆盖上升同时精度下降则应视为覆盖改善伴随潜在误检。详细数值见 analysis.json。
- 基于这 13 个本地样本，path_collinear_v1 是否适合作为后续候选，需结合覆盖与精度的总体变化评估；该结果不能作为官方赛分结论。
- 现有导出产物没有 group_id/path_id/源边 sidecar，无法核实共线合并是否跨越源路径边界；本轮没有发现可从最终 JSON 单独确认的跨路径/跨网络合并证据。
- 目前不建议切换默认后端；默认继续 legacy_v2，直到补齐来源追溯验证并完成负责人认可的准确性评估。

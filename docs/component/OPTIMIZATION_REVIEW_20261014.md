# YOLO + PP-OCRv5的优化空间（2026-10-14）

有优化空间。本轮对前150例的已保存完整预测进行只读错误分析，没有训练、调参或改变默认算法。最值得优先尝试的是Component附近的局部文字识别，以及位号、型号、数值和引脚信号的角色区分与归属。

数据只来自0001–0150；未读取0151–0200或10_GTcase。审计脚本默认且只允许这150例，验证已有预测的评测前SHA256，日志记录实际编号。结果与原评分记录严格一致：GT器件6080个、正确匹配2315个，当前宏平均ComponentF1为0.396791。本地评分器仍不是官方评分器。

## 失分分类

按现有评分器的首次未通过条件归类，每个GT器件只进入一类：

| 结果或条件 | 数量 |
|---|---:|
| 完全符合当前Component匹配条件 | 2315 |
| 无正确key匹配，但存在同类型、bbox误差不超过20像素的预测 | 1828 |
| 无正确key匹配，近位置仅有其他类型预测 | 374 |
| 无正确key，也没有近位置预测 | 882 |
| key/type匹配，但bbox超过20像素门限 | 122 |
| key/type/bbox匹配，电阻或电容数值缺失 | 240 |
| key/type/bbox匹配，电阻或电容数值不一致 | 184 |
| key/type/bbox匹配，芯片Name不一致 | 115 |
| key匹配但type不一致 | 20 |
| 合计 | 6080 |

这不是检测AP，也不是纯漏检/误检分类。“近位置预测存在”不要求一对一匹配；同名器件框错位也可能来自位号绑定错误。不能把上述数字直接换算成将来能提高的F1。

对电阻、电容、芯片三类，类型及近位置预测存在而key不匹配的数量分别为357、368、387，合计1112。它们是文字识别和空间归属值得优先检查的对象。

上一轮独立一对一几何诊断只要求type正确、bbox误差不超过20像素，宏平均F1为0.819758，完整Component为0.396791。二者口径不同；差距说明文字/身份字段占了相当一部分失分，0.819758不是可实现成绩的承诺或官方评分上限。

## 可以直接针对的文字问题

在key、type和bbox已经正确的条件下，424个电阻/电容数值仍缺失或不一致，115个芯片型号不一致。这些错误提供了在检测框和器件数量保持不变时改进Component的方向。

例如0001/U1，目标Name为RP2350B，当前输出GPI024；0006/U2，目标HS96L03W2C03，输出HS98L03W2C03。前者值得检查型号候选与引脚信号的角色区分，后者值得检查局部字符读数。示例本身不能证明全部115处都由同一机制导致。

## 需要单独核查的评分与标注问题

- 1828处同类型/近位置但无正确key的情况中，582处GT使用“∅编号”。这些编号不能当作普通可读位号；GND已经有独立空间匹配规则，其他类型的编号含义需单独核查。
- 另有110处目标key的精确字符串出现在全图OCR中，可作为归属排查对象；1136处没有这个精确字符串。这种检查不解析合并文字或确认局部位置，因此不能把1136处直接称为OCR漏识别。
- 424处数值错误中，92处GT为null、预测非空；其余332处GT非空。前者需要核对原图、标注及“必要文本”的实际评分口径，不能未经核查就删掉已读出的数值。
- 有11处key差异仅为大小写，但现有本地评分器要求普通key直接匹配。它们是1828处的子集，不应重复相加，也不能据此把所有key统一改成小写。

这些限制需要和可观测的文字错误分开，避免为了本地分数修改正确输出。

## 建议的下一步实验

1. **Component局部二次OCR**：围绕电阻、电容和芯片的候选文字区域进行更细的裁剪与放大，补充位号、数值和型号读数。当前PP-OCRv5已经做全图及768像素切片识别，下一步应实验更贴近器件的区域，而不是重复同一全图结果。
2. **文字角色与空间归属联合判断**：结合器件类型、文字内容、所在位置与引脚排列，区分位号、型号、数值和信号；尤其检查芯片附近的GPIO、Vout等文本是否被选为型号。沿用图像证据和现有输出契约，不以GT在推理时补字段。
3. **再处理视觉分类和位置问题**：单独评估电感、端口、LED等弱类别及器件框误差。已有独立Faster R-CNN实验尚未整体胜过YOLO，应先建立按类别的错误证据，再选择训练或替换路线。
4. **同时关注下游指标**：上一轮新OCR令NetLine宏平均F1从0.037504降至0.036363，辅助PinPair也下降。Component局部新增文字候选应先在本模块内使用，并进行完整Pin/Net对照，检查文字抑制或归属变化的影响。

优先级为局部文字与角色归属，其次是视觉弱类别。未来实验继续遵守前150例白名单、预测先保存后评分，并保留负向结果；本轮审计没有实施上述新算法，也没有新增成绩。

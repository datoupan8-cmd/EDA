# V4.1 相对同门第二版的升级说明

## 一、结论

同门第二版提供了本次融合最关键的视觉前端：继续训练后的 YOLO11n、切片推理、全图坐标恢复和重复框抑制。V4.1 没有重新训练这个模型，因此元件 `bbox + type` 检测能力主要来自同门第二版。

V4.1 的升级集中在检测后的文字理解、字段生成、官方格式兼容和工程可靠性。它把同门的 YOLO 检测结果接入原 V3/V4 的 OCR、全局关联、Pin/Wire/Topology 和严格输出链路，使元件结果更适合直接参与本比赛。

## 二、融合后新增的升级

### 1. OCR 从单一路径升级为双路互补

V4.1 同时执行：

```text
RapidOCR 对整张图识别一次
+
EasyOCR 对全部 640×640 分块逐块识别
↓
恢复全图坐标
↓
跨分块去重并合并文字
```

这种方法保留 RapidOCR 的整体稳定性，同时利用 EasyOCR 补充局部小字。无训练重叠 dev30 上，位号 OCR micro F1 从 0.5101 提高到 0.5532。

### 2. YOLO 与文字语义彻底解耦

同门 YOLO 在 V4.1 中只负责：

- 元件位置 `bbox`
- 元件类别 `type`
- 检测置信度

它不直接生成 R1、C2、U3、10k 或芯片型号。位号、Name 和 Value 由 OCR 与文字关联模块分别处理，降低检测模型同时承担视觉定位和字符串语义的风险。

### 3. 位号采用全局一对一关联

V4.1 为每个元件和每个候选位号计算匹配分数，综合考虑：

- 空间距离和相对方向
- OCR 置信度
- 文字尺寸
- 元件类型与位号前缀兼容性
- 一个文字只能分配给一个元件

最后使用全局匹配，避免一个 R1 同时分给两个电阻，也减少 R、C、U 等不同类别间的错配。

### 4. 扩展了官方数据中的真实位号规则

融合版本补充了最新版官方开发数据中实际出现的电阻位号族，例如 `RC`、`RES`、`RP`、`RT`、`RV`、`RVC`，同时避免把 `REF5040` 一类型号误判为电阻位号。

### 5. 区分可观察位号与内部编号

V4.1 不要求 OCR 识别 PNG 中通常不存在的 `∅86` 等内部对象编号，也不把异常 pin suffix 直接当作可靠物理脚号。缺少文字证据时使用内部低置信占位，并在 diagnostics 中记录，避免自动生成 U1、U2 后冒充识别成功。

### 6. 删除高风险的特定案例逻辑

V4.1 没有接入同门第二版中的以下逻辑：

- 按阅读顺序自动补 U1、Q1 等位号
- 面向 0057 特定尺寸的 MOSFET 模板
- 大小写宽松结果直接作为主评测

这些方法可能在个别图片上有效，但缺少跨图泛化证据，并可能与正式评分的字符串语义冲突。

### 7. 增加官方合同校验和完整追踪

每个输出 JSON 在写盘前检查：

- 官方 component type
- 字段名、层级和数据类型
- bbox、pin、edge 坐标有效性
- hyperGraph 引用是否存在
- 左下角官方坐标系

每个 Component 还记录 proposal、designator、Name 和 Value 的来源与拒绝原因，便于区分检测错误、OCR 错误和关联错误。

### 8. 提升新环境运行可靠性

V4.1 为 YOLO 和 OCR 缓存加入模型版本、配置和权重 SHA256，防止新旧模型错误共用缓存；同时处理了首次运行目录创建和 Windows 深层路径过长问题。最终 ZIP 已在干净目录完成无缓存推理。

## 三、同条件指标变化

以下均为最新版官方 0001～0150 的本地非官方诊断结果：

| 指标 | 同门新权重接入但仍用原 V4 文字流程 | 最终 V4.1 | 变化 |
|---|---:|---:|---:|
| ComponentF1 | 0.3762 | 0.3810 | +0.0048 |
| Symbol type+bbox F1 | 0.8137 | 0.8137 | 0 |
| BBox F1 | 0.8768 | 0.8768 | 0 |
| Type accuracy | 0.9249 | 0.9249 | 0 |
| PinF1 | 0.1719 | 0.1751 | +0.0032 |
| NetHypergraphF1 | 0.1506 | 0.1579 | +0.0073 |
| NetLineF1 | 0.0263 | 0.0299 | +0.0036 |
| PinPairF1 | 0.0171 | 0.0181 | +0.0010 |
| 本地非官方总分 | 21.12 | 21.63 | +0.51 |

Symbol、BBox 和 Type 指标没有变化，证明 V4.1 没有把同一 YOLO 检测能力重复包装成新成果。最终提高主要来自新增 OCR token、文字规则和后续关联。

## 四、当前仍存在的不足

融合并非所有字段都变好。Value accuracy 从 0.5880 降到 0.5431，原因是新增 OCR token 会与真实 Value 竞争。Name 阶段在原消融中没有稳定收益，因此 V4.1 默认关闭，报告中的 NameAccuracy 不能理解为已经学会芯片型号。

此外，PinF1 仍只有 0.1751，PinPairF1 只有 0.0181。说明 Component 前端虽然提高，但引脚定位、脚号脚名和拓扑恢复仍是主要瓶颈。

## 五、最终评价

同门第二版解决了“元件在哪里、是什么类型”的主要问题；V4.1 进一步解决了“如何把检测框转换成可信、可解释、符合官方格式的比赛 Component”。

因此，本次融合的主要价值不是替换同门的 YOLO，而是为它补齐双路 OCR、全局位号关联、内部 ID 处理、官方合同校验、下游兼容和可追踪诊断。完整 150 例总分提高 0.51，但 Value 回退仍需在下一阶段修复。

`OFFICIAL_SCORE = FALSE`

`SEALED HOLDOUT USED FOR DEVELOPMENT = FALSE`
